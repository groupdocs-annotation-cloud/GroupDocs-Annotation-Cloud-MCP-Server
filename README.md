# GroupDocs.Annotation Cloud MCP Server

MCP server for GroupDocs.Annotation Cloud with product tools and shared cloud storage tools.

## Core product tools

- `annotation_supported_formats`
- `annotation_get_info` / `annotation_extract` / `annotation_search` / `annotation_split` / `annotation_compare` / `annotation_assemble` (as applicable)

## Shared storage tools

- `file_upload`, `file_upload_local`
- `file_download`, `file_download_local`
- `folder_list`, `file_exists`, `folder_exists`
- `file_delete`, `folder_delete`

## Environment

```
CLIENT_ID=your-client-id
CLIENT_SECRET=your-client-secret
MCP_PORT=8000
```

Server endpoint: `http://127.0.0.1:8000/mcp`
